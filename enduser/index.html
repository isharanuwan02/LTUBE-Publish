    End User Guide for LTUBE

    Following guide is for the user to publish a video in LTUBe

    To try the following steps, you need to have an account from EduID

    1. First, access the LTUBE and sign in(https://ltube.learn.ac.lk)

    1. Then log in using your EduId credentials

    1. Click on the upload media button

    1. You will see this page

    1. Select your video file

    1. Wait for the upload to finish, then click on the View media

    Edit the details for the video

    1. Now click the "edit Media" button

    2. Add relevant hashtags, from this first tab

    3. Also add the Thumbnail for the video and enable comments

    4. From the Second Tab, you can edit the Video by trimming

    Publishing the video

    1. Please select the relevant category for the video, then go for publishing

    2. Removing the video

    Playlists

    1. If you want to add the video to a playlist, click on the Save button.

    2. If you don't have playlists, then you can create them from the same popup

    3. create playlist as per your requirement

    4. then add to the relavent playlist by marking the check box

    5. then click save, it will add to the selected playlist

    This is the Guide. Go back to Home .
